# LectureWhisper

**LectureWhisper** — локальное desktop-приложение для расшифровки лекций и анализа видео с помощью `whisper.cpp`.

Программа рассчитана на длинные лекции, в том числе по программированию, где преподаватель показывает код, IDE, терминал, браузер, презентации и другие материалы на экране.

Все основные данные обрабатываются локально на компьютере.

## Возможности

- локальная расшифровка речи через `whisper.cpp`
- поддержка русского, английского и автоматического определения языка
- экспорт расшифровки в TXT
- экспорт субтитров в SRT
- анализ видео
- автоматический выбор уникальных кадров
- обнаружение смены слайдов, окон и кода
- подавление повторяющихся кадров
- сохранение кадров в исходном разрешении
- генерация `lecture_context.md`
- генерация PDF из выбранных кадров
- несколько моделей Whisper
- автоматическая рекомендация модели по характеристикам компьютера
- встроенный FFmpeg
- автономная сборка приложения

## Как работает обработка

Для аудиофайлов LectureWhisper:

1. декодирует аудио;
2. приводит его к формату, подходящему для Whisper;
3. запускает локальное распознавание речи;
4. сохраняет TXT и SRT.

Для видео LectureWhisper дополнительно:

1. извлекает аудиодорожку;
2. выполняет расшифровку;
3. анализирует изображение;
4. выбирает уникальные устойчивые состояния экрана;
5. сохраняет полноразмерные кадры;
6. связывает кадры с временными метками расшифровки;
7. при необходимости создаёт PDF.

## Уникальные кадры

LectureWhisper не сохраняет кадр каждые несколько секунд без фильтрации.

Для отбора используется отдельный алгоритм анализа изображений.

Он учитывает:

- глобальную разницу между кадрами;
- perceptual `dHash`;
- локальные изменения по сетке областей;
- изменения контуров и текста;
- небольшие изменения кода;
- стабильность нового состояния экрана;
- прокрутку и анимации;
- повторное появление уже сохранённого экрана.

Кадры для анализа уменьшаются и переводятся в grayscale, поэтому сравнение остаётся быстрым.

После того как алгоритм принимает решение сохранить кадр, в папку `frames/` помещается изображение в исходном разрешении видео.

## Результаты обработки

Для аудиофайла:

```text
transcript.txt
transcript.srt
```

Для видео:

```text
transcript.txt
transcript.srt
lecture_context.md
frames/
frames.pdf
```

`frames.pdf` создаётся только если соответствующая опция включена.

## Поддерживаемые форматы

### Аудио

```text
WAV
M4A
MP3
AAC
AIFF
CAF
```

### Видео

```text
MP4
MOV
M4V
WebM
MKV
```

Для форматов, которые система не может стабильно открыть нативными средствами, используется FFmpeg.

## Модели Whisper

Поддерживаются модели:

```text
tiny
base
small
medium
max
```

`max` соответствует модели:

```text
large-v3
```

Пример скачивания рекомендуемых моделей:

```bash
./packaging/download_models.sh tiny base small
```

Дополнительно:

```bash
./packaging/download_models.sh medium
./packaging/download_models.sh max
```

Или все сразу:

```bash
./packaging/download_models.sh tiny base small medium max
```

Модели сохраняются в:

```text
models/
```

Например:

```text
models/
├── ggml-tiny.bin
├── ggml-base.bin
├── ggml-small.bin
├── ggml-medium.bin
└── ggml-large-v3.bin
```

Большие модели не хранятся в Git.

## Выбор модели

В интерфейсе можно выбрать установленную модель Whisper.

Также доступна кнопка проверки устройства.

Она анализирует характеристики компьютера и рекомендует подходящую модель с учётом:

- объёма RAM;
- количества логических CPU;
- архитектуры процессора.

Для старых Intel Mac обычно оптимальной является модель `small`.

`medium` и `max` требуют значительно больше ресурсов и могут работать существенно медленнее.

## Основные компоненты

### Transcriber

Отвечает за запуск Whisper и получение сегментов расшифровки.

### Frame Selector

Отвечает за выбор уникальных кадров видео.

Он не зависит от AppKit, AVFoundation или Windows API и может использоваться на разных платформах.

### Media Input

Отвечает за подготовку аудио и видео к обработке.

### Bundle Writer

Создаёт итоговые текстовые файлы и связывает расшифровку с выбранными кадрами.

### PDF Writer

Создаёт PDF из выбранных кадров.

## Сборка на macOS

Проект ожидает, что `whisper.cpp` расположен рядом с папкой LectureWhisper:

```text
wisper/
├── whisper.cpp/
└── LectureWhisper/
```

Пример сборки:

```bash
cd ~/Documents/wisper/LectureWhisper

cmake \
  -S . \
  -B build-release \
  -DCMAKE_BUILD_TYPE=Release \
  -DCMAKE_OSX_DEPLOYMENT_TARGET=10.15 \
  -DGGML_METAL=OFF

cmake --build build-release -j $(sysctl -n hw.ncpu)
```

Запуск собранного приложения:

```bash
./build-release/LectureWhisper.app/Contents/MacOS/LectureWhisper
```

## Создание DMG

Для создания автономного установочного образа:

```bash
./packaging/build_release.sh
```

Скрипт:

1. создаёт чистую Release-сборку;
2. компилирует приложение;
3. добавляет FFmpeg;
4. добавляет модели из `models/`;
5. подписывает приложение локальной подписью;
6. создаёт DMG.

Результат:

```text
dist/LectureWhisper-0.7-macOS-Intel.dmg
```

## Установка на macOS

1. Открыть DMG.
2. Перетащить `LectureWhisper.app` в `Applications`.
3. Запустить приложение.

Текущая сборка использует локальную ad-hoc подпись и не проходит Apple notarization.

Поэтому при первом запуске macOS может показать предупреждение безопасности.

В таком случае приложение можно открыть через:

```text
Правый клик → Open
```

## Зависимости для разработки

Для сборки проекта нужны:

- CMake
- Clang / Apple Command Line Tools
- исходники `whisper.cpp`
- FFmpeg для упаковки и fallback-обработки видео

Готовому пользователю отдельно устанавливать эти компоненты не требуется, если используется self-contained сборка.

## FFmpeg

FFmpeg используется для:

- извлечения аудио;
- поддержки WebM и MKV;
- fallback-декодирования мультимедиа;
- будущего унифицированного видео backend.

## Производительность

Скорость обработки зависит от:

- модели Whisper;
- длительности лекции;
- CPU;
- количества RAM;
- формата входного файла.

Для старых Intel Mac модель `small` обычно является разумным компромиссом между скоростью и качеством.

`medium` и `large-v3` значительно тяжелее.

## Приватность

LectureWhisper предназначен для локальной обработки данных.

Аудио, видео, расшифровки и выбранные кадры обрабатываются на компьютере пользователя.

Программа не требует отправки лекций во внешний облачный сервис для выполнения распознавания.
